## 🥊 Rediseño y Optimización: Página Web de Boxeo

¡Bienvenido al repositorio de mi proyecto de boxeo! Este desarrollo nace de la necesidad de mejorar una página web real del mundo del boxeo que presentaba serios problemas de usabilidad, diseño obsoleto y falta de adaptabilidad móvil. El objetivo principal fue reconstruirla desde cero para ofrecer una experiencia de usuario fluida, moderna y visualmente impactante.

## 🚀 Objetivo del Proyecto

El propósito de este proyecto fue identificar las fallas de la plataforma original y resolverlas mediante un desarrollo web limpio. Las mejoras clave implementadas incluyen:
* **Diseño moderno:** Estética alineada al dinamismo y la fuerza del boxeo.
* **Interfaz intuitiva:** Navegación simplificada para que el usuario encuentre información rápidamente.
* **Responsividad total:** Adaptación perfecta a celulares, tablets y computadoras.
* **Optimización de código:** Estructura limpia y fácil de mantener.

## 🛠️ Tecnologías Utilizadas

Para el desarrollo de la interfaz se utilizaron herramientas estándar de la industria que garantizan un rendimiento óptimo:
* **HTML5:** Estructuración semántica del contenido de la página.
* **CSS3:** Estilos personalizados, tipografías y detalles visuales únicos.
* **Bootstrap 5:** Framework utilizado para acelerar el desarrollo del diseño responsive y los componentes interactivos (como barras de navegación, grillas y botones).

## ✨ Características Principales

* 📱 **Layout Responsive:** Gracias a Bootstrap, la página se ve excelente en cualquier tamaño de pantalla.
* ⚡ **Carga Rápida:** Código optimizado sin sobrecarga de scripts innecesarios.
* 🎨 **Paleta de Colores Temática:** Uso de contrastes fuertes que capturan la esencia e intensidad del deporte.
* 📂 **Estructura Modular:** Archivos organizados de forma clara para facilitar futuras actualizaciones.
